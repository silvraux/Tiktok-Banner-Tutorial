▣02 / Chromebook · ChromeOS

Install on Chromebook

!
RequirementYour Chromebook must be a 2019 model or newer to support the Linux environment needed for this method. No Developer Mode or data wipe is required.
STEP 1

Turn on Linux & ADB Debugging

  1. Open Chromebook Settings > Developers (in the left menu).
  2. Turn ON Linux development environment and complete the setup.
  3. Under the Linux section, click Develop Android apps and toggle ON Enable ADB debugging.
  4. Click Restart when prompted. After rebooting, click Confirm on the ADB prompt.
STEP 2

Set up ADB in Terminal

  1. Open your app launcher and launch the Terminal app (click Penguin).
  2. Type the following commands one by one, pressing Enter after each (press Y and Enter when asked to confirm):
sudo apt update
sudo apt install adb
  1. Once installed, type this command and press Enter:
adb connect arc
  1. When the Allow USB debugging? pop-up appears on your screen, check Always allow from this computer and click OK.
  2. Run adb connect arc one more time to verify it says already connected.
STEP 3

Move & Install the APK

  1. Open the ChromeOS Files app and drag your downloaded APK file into the Linux files folder.
  2. Go back to the Terminal app and run:
adb install "exact_file_name.apk"

Keep the quotation marks around the file name, especially if it has spaces or parentheses!

  1. Wait for Performing Streamed Install to finish and say Success. Your app is now in your Chromebook app launcher!
